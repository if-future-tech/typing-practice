# タイピング練習サイト

GitHub Pagesで動作する純粋な静的HTML/CSS/JavaScriptのタイピング練習アプリケーションです。

## 機能

### 基本機能
- **QWERTYソフトキーボード表示**
  - ホームポジションの強調表示（青色ハイライト）
  - 押下中のキーの強調表示（紫色ハイライト）
  - 次に押すべきキーの強調表示（黄色アニメーション）

- **カテゴリ別ランダム出題**
  - 基本単語
  - プログラミング
  - 長文
  - 数字・記号

- **リアルタイム入力判定**
  - 正誤判定
  - ミス時の警告音

- **スコア集計**
  - 正解数
  - ミス数
  - 精度（％）
  - WPM（Words Per Minute）
  - 経過時間

### 追加機能
- **テロップアニメーション**
  - 出題エリアで問題がスライドインするアニメーション

- **音声機能**
  - 効果音のON/OFF切り替え
  - BGMのON/OFF切り替え

- **季節のパーティクルエフェクト**
  - 春：桜の花びら
  - 夏：ホタルの光
  - 秋：落ち葉
  - 冬：雪の結晶

## ファイル構成

```
/
├── index.html      # メインHTMLファイル
├── style.css       # スタイルシート
├── app.js          # JavaScriptロジック
├── words.json      # 問題データ
└── README.md       # このファイル
```

## GitHub Pagesでの公開方法

1. GitHubリポジトリを作成
2. すべてのファイルをリポジトリにプッシュ
3. リポジトリの Settings → Pages で、Sourceを`main`ブランチに設定
4. 公開されたURLにアクセス

## ローカルでの実行

HTTPサーバーが必要です（`words.json`のfetchのため）。

### Python 3を使用する場合
```bash
python -m http.server 8000
```

### Node.jsのhttp-serverを使用する場合
```bash
npx http-server
```

その後、ブラウザで `http://localhost:8000` にアクセスしてください。

## 使い方

1. カテゴリを選択
2. 「スタート」ボタンをクリック
3. 表示された問題を入力エリアに入力
4. ホームポジションを意識して練習
